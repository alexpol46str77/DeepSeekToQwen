# DeepSeek → Qwen Chat Local

Локальное веб-приложение для продолжения старых диалогов из **DeepSeek Chat** с помощью локальной нейросети **Qwen3-VL-8B** (через LM Studio). 

Больше никаких лимитов на хранение истории, никаких утечек данных — все ваши диалоги лежат у вас на компьютере в виде обычных JSON-файлов.

## 🚀 Возможности

- 📥 **Импорт архива DeepSeek**: разбирает `conversations.json` и раскладывает диалоги по отдельным файлам.
- 🗂 **Удобный список чатов**: сортировка по дате (новые сверху), отображение количества сообщений.
- 💬 **Продолжение диалога**: выберите любой чат из истории и задавайте новые вопросы. Qwen будет помнить контекст именно этого диалога.
- 💾 **Автосохранение**: все новые сообщения автоматически сохраняются в локальные JSON-файлы в папке `my_chats`.
- ⚙️ **Гибкие настройки**: регулировка температуры, максимального количества токенов и глубины контекста прямо в интерфейсе.

## 🛠 Требования

- **Windows** (или Linux/macOS) с установленным [Python 3.10+](https://www.python.org/downloads/)
- [LM Studio](https://lmstudio.ai/) с загруженной моделью `Qwen3-VL-8B-Instruct` (или любой другой, поддерживающей OpenAI API)
- Распакованный архив из DeepSeek (файл `conversations.json`)
